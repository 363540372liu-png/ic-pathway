# 自适应教学改造与验收记录

## 第 10 课

参考 HTML 的位选与切片明确写着固定样本，但题目和可编辑位图并排。现在同一快照驱动题目、参考答案、高亮和解析。输入或题目范围变化时，清理对应作答并将先前通过改为需要复习。题目签名阻止导入或合并后把不同样本的通过状态误配到当前题。课程目录保留历史完成，步骤标签区分未开始、已阅读或操作、已完成练习和需要复习。

完整代码之后加入改一行和补表达式两题，再写交换模块。表达式检查只识别两种已收录等价形式，任意 RTL 仍需独立工具验证。课末保留补零扩展、原 Bug 修复、16 位独立实现和情境分析。保留旧题编号、原草稿及独立练习的自查记录。窄屏用可横向滚动的位组，按钮实际至少 44 px。

## 课程覆盖

[逐课矩阵](ADAPTIVE_COURSE_MATRIX.md) 记录 56 节 HDL 与 27 节 FPGA 工程课的教学类型、已有依赖、示范位置、练习、独立任务，另列最小 LED 项目。按课把已有练习放在概念、图示或代码旁，新推导题给学生先作答再展开思路的机会。第一条基础补读默认展开，后续阅读仍可按需展开。FPGA 保留工程流程、无板和真实板模式，以及各厂商的工具说明。

组件包括二进制位权、真值表和 LED 允许沿三个模型，以及复用的接线、波形、协议、时序窗口和代码行联动。新增模型只在相关课程挂载。浏览器封闭题、自查、编译、功能仿真及板测分别看待。

## 验收范围

- Chromium 实测第 10 课的动态位选、通过状态失效、重答、旧题入口和等价补全。检查数字门、NBA 和 FPGA 综合页的交互或练习位置。
- Chromium 的 320、390、768、820、1024、1280、1440 px 文档宽度下测量第 10 课。整页没有水平溢出，窄屏位按钮为 44 px，位组可横向滚动。未测实体触控设备的软键盘。
- 本地回归覆盖两代客户端写入、导入合并、旧草稿、旧题索引、动态题签名和课程配置。未在正式站使用真实账户写入或测试。
- 教学模型通过 JavaScript 语义测试。当前执行环境未提供 Icarus Verilog、pyslang 或 Yosys，真实 HDL 编译、仿真和板测未验证。
- 本轮是覆盖全部现行 HDL/FPGA 课程的渐进改造。第 10 课重做了步骤与状态。其余课程保留原讲解主结构，补充逐课推导与就近练习。更深的逐段语义重写、每课新概念即时练习与零基础试读仍需逐课完成。历史 24 节参考课继续可读，未重新编写。
