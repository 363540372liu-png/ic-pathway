# 从零开始走读 · v4.3.1

本次对照每课的开场、规格、例子与练习入口。下表列出学生应能从例子推出的下一步。工程参考课单列，以免把学校的 VCS、DC 环境当作主线路径的前提。

## 主线与选修

| 课程 | 原入口 | 修改或保留的依据 | 对照任务 |
|---|---|---|---|
| 怎么学：先认识电路，再认识语言 (orientation) | 两个开关都打开，灯才亮。这句话已经是一份很小的设计需求。先不碰工具：输入是什么，输出是什么，四种输入各会得到什么结果？ | 想象桌上只有两个开关和一盏灯。我们能拨动开关，所以开关的位置叫输入；我们想观察灯，所以灯的亮灭叫输出。给开关起名 a、b，约定 1 表示打开、0 表示关上。写 10 时，左边说 a 已打开，右边说 b 还关着。规则是两个都打开才亮。现在只拨开 a，灯该亮吗？ | 把开关规则写成四行输出：a/b=00、01、10、11。 |
| bit、二进制与常量写法 (numbers) | 四根只能表示0或1的线，能给多少个不同编号？不是4个，也不是从0数到16；先把每根线代表的位权写出来。 | 一根线能表示 0 或 1。给它旁边再添一根线，两根就有 00、01、10、11 四种排列。怎样用它们顺次表示零、一、二、三？约定右边的 1 算一份，左边的 1 算两份。因此 10 是一个二加零个一。每向左移一格，一格所代表的份数翻倍，这个份数叫位权。 | 把十进制13写成四位二进制，不加进制前缀。 |
| 与、或、非、异或：先画真值表 (logic-gates) | 一个控制器有两种要求：“两个条件都满足才开灯”和“只要有一个满足就报警”。同样两个输入，为什么要接不同的门？ | 把电源开关和盖子合上的开关都接到机器上。规定两个都闭合才允许启动。用 1 表示闭合，只看此刻两个开关的位置就能决定结果，这叫组合逻辑。把每种输入和对应的输出各写一行，这张表叫真值表。实现这个“都满足”规则的电路叫与门。 | 依次输入00、01、10、11，填写异或的四个输出。 |
| 布尔代数与译码器：从真值表得到电路 (boolean-decoder) | 地址a=10时，只想选中四条输出中的第2条，其余都关掉。怎样从真值表一步步得到这四个输出？ | 有四个抽屉，各装一盏灯，编号从 0 到 3。你手里却只有两根选择线。把这两位合起来当编号，也就是地址：左线为 1、右线为 0，编号就是二。译码器把一个编号变成一组开关，只点亮同号的灯。下文的 y[2] 就是编号 2 的灯，四灯按 3、2、1、0 排列。 | en=1，地址依次00、01、10、11，填写4位译码输出。 |
| 先懂电路，再读代码 (mindset) | 把两条assign交换位置，y和z会不会交换先后？先想一下：图上的与门和或门会因为我们换了两行字就先后开始工作吗？ | 把同一对开关同时接到两块电路上：一块要求都闭合，另一块只要求至少一个闭合。只闭合左边的开关，前一盏灯灭，后一盏亮。画图时先画哪一块都不影响接线。HDL 也能用两行文字分别写下这两条长期存在的连接关系。 | 画出 a、b 到两个输出的连线，说明是否需要时钟。 |
| 电平与边沿：锁存器、触发器、寄存器 (storage) | 输入D在时钟高电平期间先变1、再变0。输出Q是一路跟着变，还是只在某个时刻取一次值？这个问题把组合电路、锁存器和触发器区分开了。 | 先看同一个输入怎样得到两种输出。把一根线叫 D，把观察点叫 Q。如果直接连线，D 变成 1，Q 也会随它变。如果只允许在铃响的一刻记下 D，铃声过后 D 再变，Q 仍保留记下的值。数字电路用一根反复在 0、1 之间变化的时钟线规定这种时刻。从 0 变到 1 的瞬间叫上升沿；一直为 1 的那段时间叫高电平。 | DFF初Q=0，第一上升沿D=1，沿后D改0但没有新沿。填“沿后Q、D改后Q”。 |
| 从第一个与门到模块实例连接 (module) | 现在要让两个开关都打开时灯才亮。真值表已经给出规则，但怎样把这个规则交给工具？先只写一份电路，不放第二个模块：module and2 开始一个名叫and2的定义，endmodule结束定义。它们之间写接口和逻辑关系。这里的“结束”是文件结构结束，不是电路停止运行。 | 把与门填空移到首个完整模块后，先写单模块再接实例。 | 先独立写or2并列出四组真值表；再用两个and2实现result=x & z & enable。解释内部pair由谁驱动、由谁读取。 |
| 第一次编译与四组输入仿真 (tool-start) | 文件里有一个and2模块，第一次运行工具最值得确认什么？先别同时处理波形和综合，先让工具确实读到这个文件、找到这个顶层。 | 刚写好的 and2 是一段文本。把它存成 and2.v，打开终端，也就是输入工具命令的窗口，进入这个文件所在的目录。下面先让工具读取文件并找到模块名，再给它四组开关输入。第一步能抓到少写分号，第二步才能发现把与门写成了或门。 | 记录你的系统、版本和第一条编译结果；还没安装时写下待办。 |
| wire、reg 与 assign (net-var) | 与门已能用assign写出。现在把y2放进always @(*)里，为什么output必须从wire改成reg？always建立一个独立仿真过程，@(*)等待过程所读的a、b发生变化；变化后重新执行块中的y2=a&b。这里的=先算右侧再写过程变量。没有延迟和沿触发，最终仍然是与门。reg只说明赋值途径，不能单凭名字断言存在寄存器。 | 在与门里动一下输入，输出就该跟着变。熟悉的 assign y = a & b; 把关系一直连到线上。还有一种写法：每当输入变化，就重新算一次，把结果写到变量。Verilog 用 always @(*) 表达这样的组合过程，用 reg 声明过程写入的变量。两种写法都给每种输入一个明确输出，所以这里都用不到存储。 | 把与门改成或门，分别用assign和always写。 |
| 向量、位选、切片与拼接 (vectors) | 八根信号线可以共用一个名字。先给它们编号，再从这组线里选出你需要的一根。 | 保留已将声明、选位、切片、拼接、复制分开的交互页。 | 将一个4位无符号数a零扩展为8位。 |
| 0、1、X、Z 与初始化 (four-state) | 刚开始仿真，为什么有的线是X，有的却是Z？先找它有没有驱动，再看保存的状态有没有被初始化。 | 仿真刚开始，工具可能还不知道一盏灯应该亮还是灭。波形上的 X 表示它现在无法确定是 0 还是 1。另一种情况是引脚没有任何东西在驱动，普通 wire 在仿真里会显示 Z，表示高阻。可以拿未知位分别当 0、1 试算：若两种可能得到同一结果，输出就仍然确定。 | 解释为何计数器没有复位时可能一直是X。 |
| 算术、位运算、逻辑与比较 (operators) | a=1010、b=0101，a&b、a&&b和&a为什么给出三个不同结果？它们虽然都带&，处理的对象不同。 | 先只算一种与。令 a 的四位为 1010，b 的四位为 0101，把每一列单独送进一个与门。四列里没有一列同时为 1，所以四位结果是 0000。写进 Verilog 时，二进制数要标明进制，例如 4'b1010；裸写 1010 是十进制整数。接下来比较三个问题：哪些位同时为 1？两个数是否都非零？一个数是否每位都为 1？ | 计算 a\|b、a^b、!a，并注明位宽。 |
| 位宽、截断与补码 (width-sign) | 4位最大数15再加1，数学上是16，为什么输出却可能回到0？把16写成二进制10000，答案就在多出来的那一位里。 | 用四盏灯显示计数，从 1110 再加一，变成 1111。再加一需要第五盏灯，完整结果是 10000；如果只接了低四位，看到的就是 0000。把多出来的高位丢掉叫截断。先按无符号数算清楚这一次，再问同样四根线怎样表示负数。 | 两个8位无符号数最大和多少，结果需几位？ |
| 符号转换：位串不变，解释可能变 (casts) | raw=4'hF，同一串1111怎样会一边得到15，另一边得到-1？这里没有改变线上的位，而是改变了运算如何解释它。 | 用四根线表示 1111。按普通无符号位权计算是 8＋4＋2＋1＝15。若约定用四位补码表示有符号数，最高位的权改为 −8，另外三位不变，就得到 −1。扩大到八位时，怎样填上新出现的四个位置，才能仍表示原来的数？ | 给raw=1000写出sx和zx的十进制。 |
| begin/end、if/else 与组合逻辑 (branches) | sel=0选a、sel=1选b。写if之前，先问一句：两个分支是不是都能给y一个明确值？ | 手里有两组数据 a 和 b，输出端 y 只能接其中一组。另用一根线 sel 当开关，0 接 a，1 接 b；这种电路叫选择器。若 a=2、b=7，拨动 sel 时你应该看到 2 或 7。现在用 if 表示“条件为真时这样接”，用 else 表示另一种情况。 | 添加使能en：en=0时y=0，否则按sel选择。 |
| case、优先级与意外锁存器 (case-latch) | 有三个输入却用两位选择码，00、01、10都安排好了，剩下的11该输出什么？这个空缺不能交给工具猜。 | 两根选择线有四种可能，而你只有 a、b、c 三个可选输入。把 00、01、10 分别分配给它们后，第四种 11 依然可能在线上出现。先规定这时输出零，再用 case 把选择码与各条输出规则一一配对。 | 给出无存储的修复：en=0时输出0。 |
| casez：通配规则与优先级 (casez) | req=1010时两个请求同时有效，编码器该报告3还是1？只有先规定“高位优先”，代码的第一项才有依据。 | 四根请求线中可能同时有两根为 1。若规定编号大的先响应，最高位一旦为 1，低三位是什么就都无关了。把这一组输入写成 1???，问号表示这个位置不参与本项匹配。casez 从上往下找第一条匹配项，排列顺序因此也是设计的一部分。 | 给req=0000写出valid和index。 |
| for 循环：展开的是硬件还是时间？ (loops) | for循环四次，是做四拍，还是做一段组合计算？先看循环里面有没有等待时钟的事件。 | 要判断四个输入里有奇数个 1，可以拿着一个初始值 0，从最低位开始，每遇到一个 1 就翻转一次。这正是异或。试着把 0011 的四次异或写出来。for 让我们用一个编号反复描述这些连接；这里没有等待时钟，四次描述共同构成一次组合计算。 | data=1011时写出i=0到3各轮parity。 |
| parameter、localparam 与 generate (parameters) | 同一份反相器写成4位或8位，需要复制两份源码吗？参数让我们在展开电路前决定尺寸。 | 做两版按位取反的电路，一版两根输入线，一版五根。每根线上的规则都一样，差别只是重复多少份。把这个数命名为参数 W，在放入每个实例时选定它；W=2 时位号是 1、0，所以端口范围写作 [W-1:0]。 | 实例化一个4位invert模块。 |
| function：给组合计算起一个名字 (functions) | 很多地方都要算“加1”，能不能把这段组合计算取个名字？函数正好适合这种不等待时间的计算。 | 许多地方都要把一个四位数加一，并且各自只取低四位。我们可以给这条计算规则起名 inc，让调用处只给出输入。Verilog 的 function 在这里表示一段能返回计算值的描述；计算 1111 加一时，返回口的四位只装得下 0000。 | 解释函数里把返回宽度改成5位还需检查什么。 |
| 编译指令、宏与多文件边界 (directives) | 希望同一份源码在一个配置里直通、另一个配置里反相，应该用输入sel还是`ifdef？先区分“运行时切换”和“构建时选择”。 | 有的产品需要输入直通，有的需要取反。如果开机后仍能切换，就需要选择器。如果做的是两种固定版本，可以在编译前只留下其中一段文字。以反引号开头的编译指令就作用在这个阶段，运行时拨动输入不会重新选择源码。 | 解释include与实例化的区别。 |
| 多模块工程、层次与RTL task (hierarchy) | 把两个4位加法器接在一起，就自动成为8位加法器了吗？试一试0F加01，看看低半字节的进位有没有送到高半。 | 用十进制想一次 09＋01：个位写 0，还得往十位送一个 1。换成十六进制，道理相同，0F＋01 的低四位归零，需要给高四位送进位。两个各算各的四位加法器若没有这根线，高组就永远看不到低组多出来的 1。 | 在“多模块工程、层次与RTL task”中检查这个错误方案： 把sums直接当a+b。写出具体修改办法与核对步骤。 |
| 时钟边沿、D 触发器与逐拍读图 (edges) | D在一个周期里变了几次，Q到底取哪一次？我们只看clk从0跳到1前，D已经稳定成了什么。 | 把时钟想成一列交替的 0 和 1，只有由 0 变到 1 的瞬间取样。D 是待记的值，Q 是已经记住的值。假设 D 在第一个上升沿前已稳定为 1，沿后改回 0，试着在时间轴上指出 Q 第一次能变回 0 的时刻。 | D在第1个边沿前是1，第2个边沿前是0，写出Q变化。 |
| 阻塞 = 与非阻塞 <= (nba) | 来看两级寄存器：a<=d，b<=a。上升沿前d=1、a=0，那么这个沿过后b是1，还是仍为0？先别按源码从上到下“把值传过去”。 | 把两个触发器首尾相接，第一个叫 a，第二个叫 b。时钟沿前 d=1，a=0，b=0。遮住沿后的两格，只填各自输入端现在接到什么：第一级接 d，读到 1；第二级接 a，读到 0。同一个沿各记各的输入，于是沿后是 a=1、b=0。Verilog 用 a<=d 和 b<=a 来描述这种采样后更新。 | 保持d=1再给一沿，a和b是多少？ |
| 同步复位、异步复位与使能 (reset) | 复位拉低的一瞬间，Q一定马上清零吗？答案取决于规格是同步复位还是异步复位，不取决于信号名里有没有_n。 | 计数从哪里开始？用一根复位线要求寄存器回到已知值。名字 rst_n 中的 n 提醒我们这里用 0 表示请求复位。假设 Q=5，在两个沿之间拉低它。若只在上升沿判断复位，眼下仍看见 5；若允许复位本身立即触发清零，眼下就会变 0。 | rst_n=0且en=1时下一沿Q是什么？ |
| 从规格到完整计数器 (counter) | 计数器为什么不会沿后立刻一口气加到最大？把它画成Q经过加法器回到D，就能看出中间还隔着一份寄存器。 | 把寄存器的输出 Q 接到一个加一器，再把结果接回输入 D。沿前 Q=2，加一器已经算出 D=3，但寄存器要等上升沿才记住 3。沿后加一器又算出 4，新的 4 仍要等下一个沿。这就是一个每拍只前进一步的计数器。 | 写出复位、计数2拍、暂停1拍、继续1拍的结果。 |
| 移位寄存器与单周期边沿脉冲 (shift-pulse) | sig已经连续两拍为1，为什么我们只想在第一拍产生pulse？需要知道的不是“现在是否为1”，而是“现在与上一拍相比有没有从0变1”。 | 假设按钮已经按住三拍，只想在刚按下那一拍给出提示。单看现在的 1，分不出刚按还是一直按。另留一个寄存器 prev 记住上次采样，当前为 1 且 prev 为 0 才发脉冲。这里先用已经属于本时钟域的信号练习。 | 画出sig依次0、1、1、0时pulse序列。 |
| 小型 ALU：选择运算与保留进位 (alu) | 同一组a、b有时相加、有时做异或，输出选择之后，carry应该留下加法时的旧值吗？先把每个操作的输出都写完整。 | 计算器上按加号和按异或键，输入可以相同，输出规则却要改变。ALU 就是能选择几种算术或逻辑操作的电路。先给四位数 1111 加 0001，五位完整结果为 10000。低四位送结果口，多出的 1 单独送进位口。若下一次选择异或，还需要给进位口一个明确值。 | 给每个op至少设计一组测试，并加上全0和最大值边界。 |
| 有限状态机：当前状态与下一状态 (fsm) | IDLE时start变1，next_state已经指向RUN，state是不是也立刻变了？先在纸上画开“候选下一状态”和“当前保存状态”两栏。 | 电机接到 start 后持续运行，即使 start 已松开；接到 finish 后才停。同样是两个按钮都松开，电机可能在转，也可能已停，取决于过去发生过什么。我们只需记住“空闲”和“运行”两种状态。先问下一拍要去哪，再用一个寄存器在时钟沿保存这个选择。 | 写出从IDLE开始start=1一拍，随后finish=1一拍的状态序列。 |
| Moore与Mealy：沿间响应和输出寄存 (moore-mealy) | 同一个“连续两个1”的检测，为什么一个输出沿间就变了，另一个要等时钟？我们用prev=1、当前bit_in从0变1来比较。 | 要检测相邻两个 1，先用 prev 记住前一位。若 prev 已为 1，当前输入在两沿之间升为 1，组合与门会立即给出检测结果。若把这个结果再存进寄存器，观察者要等到下一沿。分清观察时刻，才能比较依赖当前输入的输出和只依赖已保存状态的输出。 | 给序列1,1,0,1画mealy沿前与moore沿后结果，注明观察相位。 |
| 迈入 SystemVerilog：logic 与 bit (sv-logic) | 把reg换成logic后，电路会多出寄存器吗？还是回到我们已经用过的判断：这条赋值在什么事件下发生，需要保存过去吗？ | 把一个已经工作的与门改写为 SystemVerilog，先把输出声明为 logic，仍让同一条 assign 驱动它。输入一变输出就跟着算。再看时钟过程写入的 logic：它却能表示保存的状态。判断电路时先找驱动关系，单看声明中的类型名无法区分这两种情况。 | 把wire [7:0] data的单驱动SV变量声明写出。 |

| 03 先在仿真里接通整条数据通路 | 电脑送进一条命令，测试台能只在发送开始时看灯吗？ | 这时线上还只有第一个电平。接收器要等一个完整字节收齐，才给出一次有效指示。测试台可以先像用户一样发命令、等接收完成、看灯，再深入检查每个位。波特率在本例表示每秒传几个串口位，和每秒多少个系统时钟是两回事。 |
| 12 UART一帧为什么要有起始位和停止位 | 在终端按字符 1，线上会只有一个高电平吗？ | 终端先把这个字符编码为一个字节 0x31。写成二进制是 0011_0001，最右一位先发。接收端还要知道从哪开始数八位，所以发送端先给一个低起始位，发完数据再给高停止位。 |
| 14 接收器：在什么时候读取每一位 | 每个数据位持续八个系统周期，看到起始下降沿后，该立刻读第一个数据位吗？ | 起始低电平本身占一整个位时间。理想情况下，第 4 个周期左右还在起始位中心，第 12 个周期左右才到数据位 D0 的中心。真实接收器还受同步延迟与两端时钟误差影响，后文用计数器安排采样。 |
| 10 计数器与时钟使能：别制造第二个时钟 | 若每三个系统周期才更新一次灯的位置，需要第二根时钟线吗？ | 假设每三拍允许更新一次。在原时钟的每个上升沿看使能，只有序列 0、0、1 中的最后一沿改变灯的位置。时钟仍然每拍到达；被放慢的是状态的更新频率。 |
| 11 用状态机描述等待、接收和结束 | 灯的位置相同，可下一拍有时走一步、有时原地不动，电路还要记什么？ | 要另记当前是在运行还是暂停。位置与模式是两份状态：暂停时只让位置保持，模式仍须接收恢复命令。若把整个时钟停掉，保存模式的寄存器也收不到恢复操作。 |
| 13 扩展：发送器与回显接口 | 发到一个字节的第三位时，上游换了下一个字节，后五位应该来自谁？ | 接收方期望一整帧属于同一笔输入。接受发送请求的那一沿就保存八位数据，忙时只从保存的副本逐位取值。若一直读外部 data，前后半帧就可能来自两个字节。 |
| 22 扩展：流水线里的样本与气泡 | 两笔数据之间留一个空拍，下一级怎样知道这一拍可以忽略？ | 数据旁边还要有一位 valid，表示这一格装着有意义的样本。空拍可以留着旧数据，只要有效位为 0。同一个时钟沿同时传递数据和有效位，下游才能把二者配对。 |
| 23 扩展：同步RAM的地址与数据相差哪一拍 | 沿前地址是 1，沿后立刻改成 2，刚更新的读口对应哪一格？ | 本例寄存读口沿上采到地址 1，于是沿后输出第 1 格的字。地址 2 要等下一次读取。另一个同沿寄存器只能采到读口更新之前的值，所以画表时把地址、沿后读口和下游采样分三列。 |
| 24 扩展：FIFO满空时到底接不接受请求 | 写入 A 后，在没有读请求时能从输出口直接拿 A 吗？ | 本例是寄存读输出，成功读的沿后才配出数据和 out_valid。主线的首字直通示例在非空时就展示队首。两者都先进先出，但同一份测试台必须按所用读口的时刻核对。 |
| 25 扩展：背压时怎样保存一笔数据 | 下游没准备好，数据 5A 在三次时钟沿都出现，算发了三次吗？ | 先逐沿配对 valid 与 ready。双方都为 1 的沿才消费一次；等待时，同一笔数据重复出现是在保持。若把计数器写成每见 valid 就加一，就会误报传输了三笔。 |
| 26 扩展：位宽、舍入与饱和 | 若要求八位无符号输出，数学结果为 300，怎样得到 44 或 255？ | 300 等于 256＋44，低八位自然留下 44。这是截断。若规格要求强信号达到上限就封顶，需要在保留完整结果时先和 255 比较，超过就输出 255，这叫饱和。 |
| 15 扩展：PWM如何改变平均亮度 | 一个周期内灯三拍亮、一拍灭，引脚会输出四分之三的电压吗？ | 数字输出在高低电平之间切换。四拍中有三拍有效，叫 75% 占空比；改变的是点亮时间的比例。重复速度足够快时，人眼会感到平均亮度变化。 |
| 04 综合：从代码走到逻辑网表 | 你能在综合结果里找到测试台的时钟发生器吗？ | 设计的时钟来自顶层端口，测试台用延时产生的时钟只负责实验。综合从设计顶层出发，只翻译它包含的电路。先在顶层找 led_pin，再去报告里确认设计顶层和目标器件，才能判断报告说的是哪一份电路。 |
| 05 顺着综合网表找回RTL里的信号 | 输出端名被保留下来，内部寄存器却改了名，怎样认出它？ | 从 led_pin 沿连线往输入方向追。如果遇到取反或选择逻辑，先问它是否只是适配亮灯极性；继续追到保存灯状态的寄存器。看谁给它数据、何时允许更新，比在报告里搜索原变量名更可靠。 |
| 06 LUT、FF、RAM与DSP分别做了什么 | 四位计数器有十六个状态，要用十六个触发器吗？ | 四个触发器各记一位，合起来已经能表示十六种组合。加一和检测终值还需要组合逻辑。先分开估算“要记几位”和“要算什么”，再对照资源表；未使用或恒定的位也可能被综合优化掉。 |
| 18 面积与速度：同一功能的两种实现 | 把两个加法器合成一个，运算结果相同，时间代价也相同吗？ | 先选再加时，输入经过选择器之后才能进入加法器。先并行做两次加法再选择时，选择器在另一端。纸上的运算数只给出假设；用相同器件、相同时钟约束和相同输入输出寄存器比较报告。 |
| 07 时钟与外部接口的时间约束 | 把约束文件里的周期从 20 ns 改成 10 ns，板上的灯就会快一倍吗？ | 外部振荡器仍按原频率送出时钟。约束改变的是实现工具检查的时间预算。50 MHz 是每秒五千万个周期，每个周期 20 ns；先查板卡实际频率，再把对应周期写进时钟约束。 |
| 08 从原理图找到引脚、电压和极性 | 板上标着 LED1，能直接把 LED1 当芯片管脚号吗？ | LED1 是板上元件编号。沿原理图找到连接它的网络，再看这条网络连到 FPGA 封装的哪个脚位。最后才把 RTL 端口名绑定到该脚位，并按供电选择 I/O 标准。低有效 LED 还要在输出处处理亮灭极性。 |
| 27 异步串口输入与复位释放的边界 | 外部输入只是一个高低电平，为什么不能把它直接扇出给几个状态判断？ | 外部变化可能紧靠本地采样沿，第一级寄存器可能来不及稳定。把它只接到同步链的下一层，给它恢复时间，再从第二级取信号。两级同步降低风险；很短的脉冲仍可能落在两沿之间而被漏掉。 |
| 19 布局布线与设计规则：网表还缺什么 | 网表说寄存器 A 连到寄存器 B，这根线究竟多长？ | 综合只确定逻辑关系。放置要挑两个实际位置，布线还要从可用连线中找一条路。距离和拥挤程度会改变传播延迟，所以实现后要再读时序，并检查管脚等物理规则。 |
| 17 沿着一条路径读Setup与Hold报告 | 报告写 setup slack = −0.4 ns，负号说的是哪两件事的先后？ | 假设最晚只许在 9.0 ns 到达，报告算出数据 9.4 ns 才到。建立余量等于要求减到达，得到 −0.4 ns。保持检查关心新数据是否来得太早，必须改读最短路径及对应捕获沿。 |
| 09 生成配置文件并下载到器件 | 下载后灯能闪，一断电再上电就不闪了，这一定是源码错了吗？ | 有些器件当前工作的配置存于易失存储，断电会丢失。从下载器临时配置成功，和从板载存储器上电启动，是两种不同的实验。分别记录下载方式和重新上电的结果，再查启动模式。 |
| 16 板上不亮：按信号路径缩小问题 | 串口发了命令灯没亮，先查哪一段最省事？ | 先用已知输出验证灯和管脚，再检查系统时钟与复位。只有这些工作正常，观察“收到了一个字节”的脉冲才有意义。找出最后一个仍然正确的信号，就把故障限制在它和下一个观察点之间。 |
| 21 交付验收：从干净目录重新做一遍 | 同学拿到一张 PASS 截图，能据此重做你的实验吗？ | 截图没有说明编译了哪些文件、使用哪个顶层和参数。让同学从空目录按文件列表运行同一份测试，再比对预期和日志。只有板测过的部分才附上板卡型号、引脚约束和观察结果。 |

LED 项目单独修复了三种工具的综合、约束、实现和下载指引。现在选择项目 A 时，示例使用 led_minimal；项目 B 保留 uart_led_top。时钟约束改变工具分析的预算，实际闪烁周期由振荡器频率与 RTL 参数决定。

## 仍需实际学习验证

六道波形题的目标信号在答对前隐藏，学生要从输入和采样条件推导它。此改动保留原题索引、标准答案和历史通过记录。开放任务仍需在仿真器或实际板卡上执行，课程内自查不能验证任意 RTL。

目前没有新手在无提示条件下独立完成课程的观察数据。下一次教学评估应记录学生在哪一个符号停下、首次提交的代码、修改过程，以及能否在更换输入或位宽后解释结果。
