## 跨课程结论

- 14个新增节点重复同一个证据选择题，必须改为节点专属；保留旧答题记录但不把旧答题成功当成新题通过。
- 50个“代码补全”、50个“Bug修复”实际是选择题；六个原精讲也存在同样形式问题。适合代码的课改为真实文本输入；不适合代码的基础课改为推导/观察，避免为凑五类而超纲。
- 首字直通FIFO与寄存读FIFO保留为两个明确规格，分别给输入接受、读前/读后dout、有效位及参考模型检查位置。
- 工程验收/工具限制集中到工程课、参考说明和实验边界，不重复挤占每课正文。
- 自动回归仅检查可机械验证的重复题干、ID、结构、状态迁移。语义对应由本矩阵逐课核对，并在交付记录标明修复证据。
