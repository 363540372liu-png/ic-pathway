# 初学者桌面推演：十个第一次

这是开发者扮演初学者的逐步阅读与操作复核，不是招募真实学生完成的可用性研究。不能据此声称学习效果已得到人群验证。

|第一次|已有示范|独立任务与障碍复核|
|---|---|---|
|写module|第7课先解释定义边界、三个一位端口和标点，再给完整AND|遮住三行示例自写；不再假设已经会写与门|
|使用assign|四行真值表，解释持续驱动、&与分号|改为OR/XOR，预测11；不需要reg、always或if|
|实例化|先one_gate，再内部wire pair和两个实例|命名端口追线；填空先考单模块，修复换成p/q/lamp情境|
|使用always|第9课用同一与门比较assign与@(*)|两种方法写一位XOR；没有提前要求MUX、if/else或总线|
|非阻塞赋值|单只DFF→两个寄存器沿前/沿后推导|浏览器首沿a=1,b=0；独立题换成三位移位方向|
|计数器|复位、保持、加一三种规格和自然回绕|3位实现、模6错误终值；本课补讲旧5时回0|
|FSM|IDLE等start、RUN等finish，区分state与next|浏览器未给沿时next=RUN、busy=0，给沿才busy=1|
|Testbench|第8课先无时钟四输入实验，再完整counter TB|#5的单位/半周期/翻转/初值/TB边界均解释；本环境只展开TB，未执行vvp|
|时序报告|Setup/Hold窗口→路径max/min→偏斜|分别算两种裕量，不先要求SDC；交互不冒充实际STA|
|FPGA工程|项目A先LED九环节，B再加UART|H=3预测→H=5暂停任务；无板卡不要求伪造下载记录|

第7课强制检查：完整module、端口、wire、assign、endmodule在前三段及第一个例子；OR/XOR在第二例；类型/实例名由正文和按钮解释；单实例有完整one_gate；父子端口可高亮；双实例有完整top、pair驱动/读取说明、8组输入任务及精确源码的CXXRTL检查。

独立完成能力最终仍需真实学生试学，自动测试和本推演不能替代。
