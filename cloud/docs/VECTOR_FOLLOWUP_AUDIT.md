# 其余55课的微课审查

基于 v4.2.0 的 hdl-content.js 开篇、示例和理解题，以及 textbook-depth.js 的扩展练习。P0 优先处理可能阻断主线的首次概念，P1 补足已有前置知识但缺少练习台阶的内容，P2 为进阶内容。本轮只实施第10课，以下为逐课审查与建议。

| 课次 / ID | 优先级 | 卡点 | 建议顺序 |
|---|---|---|---|
| 1 orientation | P1 | 初次读规格就要求自行枚举四种输入 | 固定一个开关 → 补两行 → 补全真值表 |
| 2 numbers | P0 | 从四根线的编号跳到五位最大数 | 一位两值 → 两位四值 → 加位权 → 全1最大值 |
| 3 logic-gates | P0 | 从 AND/OR 切入，检查直接问 XOR | 用同一对输入试 AND → OR → 比较相同输入下的 XOR |
| 4 boolean-decoder | P0 | 同时出现二位地址、使能和输出向量 | 选择一个格子 → 接一条输出 → 扩成四条 → 加使能 |
| 5 mindset | P0 | 在模块课前用两条 assign 的顺序考查并行 | 画两条连线 → 换摆放次序 → 对照两行代码 |
| 6 storage | P0 | 同时比较组合、锁存和 DFF | 导线 → 门开/关 → 单个采样沿 → 同输入对照 |
| 7 module | P0 | 三段示范合理，理解题直接检查子端口 | 单模块四行真值表 → 改 OR → 单实例点线 → 双实例 |
| 8 tool-start | P1 | 编译成功和功能正确的差异只靠理解题 | 建文件 → 故意改错顶层 → 修正编译 → 给一条输入 |
| 9 net-var | P0 | 开篇并列 always、@(*)、reg 和阻塞赋值 | 比较端口 → 只换赋值位置 → 改输入 → 对照驱动方式 |
| 11 four-state | P1 | X、Z 同时登场，容易视作同一种未知 | 未驱动线 → 未初始化变量 → 分别输入门电路 |
| 12 operators | P0 | 同一题比较按位、逻辑和归约 | 对齐位列 → 判是否为零 → 折叠一个向量 → 三者对照 |
| 13 width-sign | P0 | 从无符号截断跳到补码读数 | 写第5位 → 截断 → 同一位串两种解释 → 补码边界 |
| 14 casts | P1 | 原位重解释与扩宽容易混淆 | 固定1111 → 标 signed → 分别扩到8位 → 比较 |
| 15 branches | P0 | 需要自行建立组合覆盖概念 | 两种 sel 各走一条 → 删 else → 补齐 |
| 16 case-latch | P0 | case 开篇，检查直接改用 if 推断锁存 | 枚举四个选择值 → 演示缺项 → 补默认 → 迁移到 if |
| 17 casez | P1 | 优先级与通配位同时参与匹配 | 单一请求 → 一位通配 → 两项匹配 → 调换顺序 |
| 18 loops | P1 | 先问是不是四拍，缺手动展开 | 手写两次 → 展开四次 → 对比有事件等待的过程 |
| 19 parameters | P1 | 展开时机与宽度变化一起出现 | 固定宽度 → 改成 W → 两个实例 → 数反相器 |
| 20 functions | P1 | 从复用直接过渡到函数返回值溢出 | 为计算命名 → 追踪返回宽度 → 试15加1 |
| 21 directives | P2 | 宏选择和运行时选择同屏 | 画两份预处理后源码 → 改宏 → 改输入对照 |
| 22 hierarchy | P1 | 进位、层次和十六进制叠加 | 两个2位加法器 → 低组独立进位 → 接入高组 → 迁移到4位 |
| 23 edges | P0 | 初读同时追踪多次 D 变化与 Q 采样 | 单沿 → 沿前 D 和沿后 Q → 加入沿间变化 |
| 24 nba | P0 | 双寄存器例缺显式的沿前值练习 | 单寄存器 → 填 a/b 旧值 → 两条 RHS → 提交 → 下一拍 |
| 25 reset | P0 | 低有效与同步/异步容易混为一谈 | 标有效电平 → 沿间拉低 → 比较 Q → 再处理释放 |
| 26 counter | P0 | 溢出、使能、复位汇入同一题 | 一拍加一 → 保持一拍 → 复位优先 → 回绕 |
| 27 shift-pulse | P1 | 同时追踪输入和 prev 的新旧值 | 单独保存前一拍 → 比较01和11 → 逐拍填表 |
| 28 alu | P1 | 直接从有进位加法切到 XOR | 单操作 → 输出选择 → 加 carry → 切换检查 |
| 29 fsm | P0 | 候选状态、当前状态和输出同题出现 | 状态图一条边 → 填候选 → 推到上升沿 → 看 busy |
| 30 moore-mealy | P1 | 直接比较两种输出，缺分别推演 | 固定 prev → 组合输出 → 寄存输出 → 同图比较 |
| 31 sv-logic | P1 | reg/logic 替换与 logic/bit 四态对照紧邻 | 保持 RTL 只换声明 → 核对驱动 → 单独测试 X |
| 32 sv-always | P1 | 过程关键字与赋值符号一起切换 | 旧组合过程 → always_comb → 原沿触发 → always_ff |
| 33 sv-latch | P1 | 显式锁存语法和保持行为压在一段 | 开门 → 关门 → 标两次 D 变化 → 对照语法 |
| 34 sv-arrays | P0 | 两对方括号首次出现就要计算容量 | 一个字的8格 → 加4个地址 → 选字 → 选位 |
| 35 sv-types | P1 | 成员、打包和总宽度检查相邻 | 两根信号 → 定义字段 → 点号读取 → 数打包位宽 |
| 36 sv-package | P0 | 开篇为 package，检查跳到 modport | 引用包类型 → 共享接口 → 两端分别标方向 |
| 37 testbench | P0 | 第一份 TB 同时引入复位、延时、观察、自检 | 改一次输入 → 看输出 → 生成时钟 → 加复位和检查 |
| 38 scheduling | P0 | 两个打印命令的区别隐含旧值与新值 | 标 RHS → 沿内读 → NBA 后读 → 连接两个打印命令 |
| 39 checking | P1 | 故意改期待值前还需看清比较点 | 手核一例 → 比较一个值 → 注入故障 → 读失败消息 |
| 40 setup-hold | P0 | 开篇是 setup，理解题跳到降频与 hold | 固定捕获沿 → 左右画窗 → 改周期 → 对照两侧 |
| 41 timing-path | P0 | 流水线开场，理解题直接算 slack | 标两沿 → 标三个延迟 → 读余量 → 拆流水级 |
| 42 clock-skew | P0 | 同时算长路径与短路径，容易混淆符号 | 两条时钟轴 → 固定数据时间 → 移捕获沿 → 读两类余量 |
| 43 multicycle | P2 | 使能与源端稳定条件同时要求 | 默认下一沿 → 标使能 → 追踪源是否稳定 → 引入约束 |
| 44 cdc | P0 | 短脉冲漏采与亚稳态易混为一谈 | 两列采样沿 → 看漏采 → 区分电平同步与事件同步 |
| 45 capstone | P1 | 从默认宽度直接跳到 W=1 | 默认宽度过一例 → 2位 → 1位 → 边界 |
| 46 synthesis-lab | P1 | 功能等价与资源比较未分层 | 用相同输入检查功能 → 数图上资源 → 看综合报告 |
| 47 memory | P0 | 同址读写同时考查 NBA 与存储器语义 | 写一拍 → 读一拍 → 同沿读写 → 按沿前后表推导 |
| 48 fifo-project | P0 | 已区分两种输出，需要明确标观测点 | 三格队列 → 空变非空 → 标读沿前后 → 对比寄存输出 |
| 49 async-fifo | P0 | 指针拥有权、同步副本与 Gray 码叠加 | 两域各走一拍 → 分开指针 → 加延迟副本 → 再看 Gray |
| 50 uart-project | P1 | A5、低位先发和周期数同时进入 | 空闲转起始 → 写出字节各位 → 每位加N格 → 停止位 |
| 51 sv-handshake | P1 | 可在三沿计数前先演示一次背压 | 单拍真值表 → 三拍计数 → ready 拉低 → 检查数据保持 |
| 52 integration | P1 | 开篇就给同拍收发最难情形 | 空缓冲接 → 满缓冲发 → 满缓冲同拍换 |
| 53 sv-tasks | P2 | 事件控制与封装混在一个例子 | 手写脉冲 → 圈两沿 → 封装 → 调用两次 |
| 54 sv-verification | P2 | 开篇讲覆盖，问题考查 randomize 失败 | 数样本重复 → 加约束 → 造冲突 → 看返回值 |
| 55 sv-assert | P2 | 复位、NBA 和断言跨度重叠 | 标采样点 → 标 NBA → 单拍性质 → 下一拍蕴含 |
| 56 advanced-map | P2 | 覆盖与正确性仅用判断题 | 写一个观察点 → 注入仍能覆盖的故障 → 补检查器 |
